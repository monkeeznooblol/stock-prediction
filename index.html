n8n Backend Workflow Changes Guide

To connect this frontend app to your n8n workflow (main.json), please make the following updates in your n8n editor:

1 Replace Chat Trigger with Webhook Node

Remove the current When chat message received node. Add a standard Webhook node configured with Method: POST.

2 Pass Stock Ticker to Equity Research Director Agent

Ensure the incoming webhook body receives { "stock_ticker": "AAPL" } and map this property into your AI Agent's input prompt (e.g. {{ $json.body.stock_ticker }}).

3 Respond to Webhook Node

At the end of your agent flow, ensure you respond with JSON containing the final analysis text, e.g.:
{ "output": "Equity Research Director recommendation report..." }

CORS & Deployment Note: When deploying this frontend on Vercel, ensure your n8n instance allows CORS requests from your Vercel domain or wildcard (*).
